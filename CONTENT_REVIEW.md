# Content Review

## Translation Choices

- **Sliding Window**: Translated as "Fenêtre Glissante".
- **Two Pointers**: Translated as "Deux Pointeurs".
- **Binary Search**: Translated as "Recherche Dichotomique" (standard French algorithm terminology).
- **Time/Space**: Kept as standard Big O notation in both languages ("O(n)", "O(log n)").
- **Tags/Categories**: Translated tags directly, but kept categories as neutral IDs mapped via `ui/fr.json`. For instance, "subarray" -> "sous-tableau", "string" -> "chaîne".
